## Pemakaian
Contoh:

```html

```

Catatan: gambar dipisahkan dari satu lembar ilustrasi komposit, lalu diperbesar dan dipertajam untuk penggunaan banner web. Rasio banner asli tiap panel dipertahankan; tidak ada bingkai putih tambahan.
